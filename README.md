# Mem2Seg-Retrieval-Augmented-Structural-Memory-for-Cross-Domain-Cell-Segmentation-
Mem2Seg is a lightweight retrieval-guided cell segmentation framework designed for robust biomedical image segmentation under cross-domain variability. The framework introduces a Prototype Memory Bank (PMB) that stores reusable structural priors learned from diverse cell morphologies. During inference, structurally similar prototypes are retrieved using a query embedding generated by a dedicated Structural Encoder, and these retrieved priors are fused with segmentation features to refine decoder representations.

Unlike conventional segmentation networks that rely solely on implicit knowledge stored in model weights, Mem2Seg explicitly separates structural knowledge storage and retrieval, enabling improved generalization across heterogeneous microscopy datasets.

The framework was evaluated on multiple biomedical segmentation datasets including BCCD, TNBC, MoNuSeg2018, NuInsSeg, PanNuke, and DSB2018.

Training Pipeline
Step 1 — Structural Representation Pretraining

The Structural Encoder is first pretrained in a self-supervised manner to learn morphology-aware representations. This stage focuses on extracting structural patterns such as cell boundaries, spatial organization, and topology rather than appearance-specific features.

Run:

python tools/pretrain_structure.py

Output:

tools/checkpoints/structure_encoder.pth

Step 2 — Prototype Memory Bank Construction

After pretraining, embeddings are extracted from all training images and clustered using K-means to construct the Prototype Memory Bank (PMB).

Run:

python tools/build_memory_bank.py

Output:

tools/outputs/prototypes_k64.pt

The PMB stores representative structural prototypes that will later be retrieved during segmentation.

Step 3 — Retrieval-Guided Segmentation Training

The segmentation model is then trained using both:

segmentation backbone features
retrieved structural priors from the PMB

During training:

The Structural Encoder generates a query embedding.
Top-T structurally similar prototypes are retrieved from the PMB.
Retrieved priors are fused with segmentation features.
The decoder produces the final segmentation mask.

Run:

python tools/train_segmentation.py

Output:

tools/outputs/seg/
